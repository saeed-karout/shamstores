# إشعارات تطبيق التوصيل (FCM)

## المصيدة الأولى: ملفّان مختلفان بالكامل

`google-services.json` الذي وضعناه في `android/app/` هو إعداد **العميل** —
يخبر التطبيق بأي مشروع Firebase يتّصل. وهو **لا يصلح للخادم إطلاقاً**.

الخادم يحتاج **مفتاح حساب خدمة** (service account) — ملفّاً آخر يُولَّد من:

> Firebase Console → ⚙️ Project settings → Service accounts → Generate new private key

المشروع الحالي: `shamstores-ba667`

الملفّ الناتج يحوي `project_id` و`client_email` و`private_key`. منه تُؤخذ
المتغيّرات الثلاثة.

> ⚠️ هذا الملفّ مفتاحٌ كاملٌ لمشروعك. لا يُرفع إلى git ولا يُلصق في محادثة.
> إن تسرّب، اسحبه من نفس الصفحة وولّد غيره.

## الضبط على Heroku

نفّذها من طرفيّتك أنت، وكلٌّ في سطر مستقلّ:

```bash
heroku config:set --app shamstores FIREBASE_PROJECT_ID=shamstores-ba667
```

```bash
heroku config:set --app shamstores FIREBASE_CLIENT_EMAIL="القيمة_من_الملف"
```

المفتاح الخاصّ متعدّد الأسطر، ويُخزَّن بسطرٍ واحد بـ`\n` نصّية — والخادم
يعيد تحويلها. انسخه من الملفّ كما هو **بعلامات الاقتباس**:

```bash
heroku config:set --app shamstores FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIE...\n-----END PRIVATE KEY-----\n"
```

للتحقّق (يعرض الأسماء لا القيم):

```bash
heroku config --app shamstores | Select-String FIREBASE
```

## التحقّق أن الإشعار يصل

إشعارٌ لا يصل له ثلاثة أسباب لا يفرّق بينها المستخدم. المسار التالي يقول
أيّها — من حساب السائق نفسه:

```
GET /api/delivery/notifications/diagnostics
```

يردّ `firebaseConfigured` و`hasToken` و`isOnline`، مع `hint` بالعربية.
ولا يكشف الرمز نفسه — بصمةً فقط.

## قناة أندرويد: `sham_orders_v2`

**يجب أن يتطابق معرّف القناة بين الخادم والتطبيق حرفاً بحرف.** أندرويد ٨
فما فوق يُسقط الإشعار بصمت إن أشار إلى قناة غير موجودة على الجهاز: لا خطأ
عند المرسِل ولا أثر عند المستقبِل — وهذه كانت العلّة الفعلية لأشهر.

- الخادم: `ANDROID_ORDERS_CHANNEL` في `backend/src/services/firebaseService.ts`
- التطبيق: `_ordersChannel` في `lib/services/push_service.dart`

**وصوت القناة لا يتغيّر بعد إنشائها على الجهاز.** لذلك يحمل المعرّف رقم
نسخة: تغيير النغمة لاحقاً يستلزم معرّفاً جديداً (`sham_orders_v3`) في
الموضعين معاً، وإلا بقي الجهاز على القديم بلا سبب ظاهر.

## متى يُرسَل إشعار — ومتى لا

| الحدث | من يُشعَر |
|---|---|
| طلب أُنشئ وعُيّن تلقائياً لأقرب سائق | ذلك السائق وحده |
| طلب صار `ready` وهو معيَّن لسائق | ذلك السائق وحده |
| طلب صار `ready` بلا سائق (البركة) | كل سائقي النشاط **المتصلين** |
| حالة لم تتغيّر فعلاً | لا أحد |
| طلب سُلّم | الزبون |

السائق غير المتصل (`isOnline = false`) لا يُوقَظ هاتفه: أنهى نوبته. وهذا
سببٌ شائع لـ«لا تصلني إشعارات» — تحقّق من الشارة في أعلى التطبيق أوّلاً.

## الرموز الميّتة

رمز FCM يتغيّر مع إعادة التثبيت ومسح البيانات والتدوير الدوري. التطبيق
يسجّله عند **كل إقلاع** لا مرّةً واحدة، والخادم يمسحه من قاعدة البيانات
حين يردّ FCM بـ`registration-token-not-registered`.
